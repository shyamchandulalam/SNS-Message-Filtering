How selective message filtering works.

What is AWS SNS?

Amazon Simple Notification Service is a fully managed pub/sub messaging service. Publishers send messages to a topic, and SNS fans them out to all subscribers.

What is Message Filtering?

Each subscription can have a JSON filter policy. SNS delivers a message only to subscribers whose policy matches the message's attributes.

Example

Message: Priority = HIGH, Region = AP-SOUTH-1
Policy A: Priority = HIGH → ● Delivered
Policy B: Priority = LOW → ● Filtered
