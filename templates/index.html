System Documentation

Amazon SNS selective message delivery architecture.

What is Amazon SNS Message Filtering?

Amazon Simple Notification Service (SNS) Message Filtering evaluates message attributes against per-subscriber filter policies. Instead of traditional broadcast pub/sub where every subscriber receives every message, SNS delivers only messages whose attributes strictly match the subscriber's filter policy.

Multi-User Platform Model

1. Admin publishes message with category=electronics, customer_tier=premium, price_usd=1500.
2. Amazon SNS evaluates all subscriber policies simultaneously.
3. Selective Delivery: Users whose filters match (e.g. Rahul, Priya, Arjun) receive the message in their dedicated SQS queues; non-matching users (Sneha) are filtered out without unnecessary compute or noise.
